PEPEPOW Trader is a cross-platform desktop application for trading the PEPEPOW (exchange ticker PEPEW) coin on NonKYC.io, covering the PEPEW/USDT and PEPEW/BNB markets. It wraps live charting, manual order entry, portfolio monitoring, and a configurable automation engine in a clean, dark-themed PyQt6 interface.

Features

*Live TradingView Lightweight Charts with an order-line overlay and a real-time forming-candle feed for illiquid markets

*Manual limit/market order entry with balance display and exchange minimum/precision enforcement

*Open-order, balance, and trade-history monitoring with one-click cancel / cancel-all

*Automation bots: Take-Profit/Stop-Loss (multi-target), Recurring DCA, Grid, Trailing Stop, Limit Chase/Peg, and Market Maker

*Dry-run mode and a PANIC button (disable all bots + cancel all orders instantly)

*API keys encrypted at rest behind a master password

*System-tray / AppIndicator support with close-to-tray

*Currently only packed in Linux Packages (.deb, .rpm, AppImage) will add Windows Support Later.
